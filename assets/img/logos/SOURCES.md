## Dark-theme display variants

`htu-dark.svg`, `pioneers-dark.svg`, `souq-dark.svg`, and `unhcr-dark.svg` retain the source geometry with dark lettering changed to light colours for contrast. Originals are preserved. MLC is inverted for the dark surface; Arab Potash is displayed in white via CSS. jQuery and MySQL receive a lighter blue CSS treatment. These are site display adaptations, not additional official brand assets.

## Light-theme hero variants

`htu-light.svg`, `pioneers-light.svg`, and `souq-light.svg` preserve the original source colours and geometry, with the same viewBox framing as their dark display counterparts. The hero selects the appropriate variant for the chosen theme so the wordmarks remain readable on both surfaces.
